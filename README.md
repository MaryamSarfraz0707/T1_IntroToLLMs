# LLM Comparison – Document Summarization

## Overview

This project was completed as part of an AI Engineering internship assignment to understand Large Language Models (LLMs) and compare their performance on a document summarization task.

The objective was to evaluate how different LLMs summarize the same document using an identical prompt and compare their outputs based on quality, accuracy, conciseness, and hallucinations.

---

## Objective

- Understand the basics of Large Language Models (LLMs)
- Compare the summarization capabilities of different AI models
- Analyze the strengths and weaknesses of each model using a fair evaluation process

---

## Models Evaluated

- ChatGPT
- Gemini
- Claude Sonnet 5
- Claude Haiku 4.5
- Llama 3.3 70B (Groq)

---

## Evaluation Criteria

Each model was evaluated using the following metrics:

- Summary Quality
- Accuracy
- Conciseness
- Hallucinations
- Overall Performance

## Methodology

1. Selected a single source document.
2. Used the same prompt for every LLM.
3. Generated summaries from each model.
4. Compared the outputs using the predefined evaluation criteria.
5. Documented observations and final conclusions in the comparison report.

## Key Takeaway

This comparison demonstrates that different LLMs have unique strengths. While all models produced useful summaries, differences were observed in writing style, level of detail, clarity, and conciseness. Evaluating multiple models helps identify the most suitable LLM for document summarization tasks.
